# Semafor M3 Implementation Plan — passive measurement, baselines, verdicts, divergence

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Semafor measures how the subscription frontier models *feel* — passively, from the CLIs' own session logs while Tim works — and turns that into learned baselines, a pure verdict ladder (OK/BUSY/DEGRADED/CRAWLING/LIMITED/UNKNOWN), and a status-page divergence banner. Spec §5–§8.4, §12–§13, **revision 2** (passive-first; active probes removed).

**Architecture:** Extends the existing SwiftPM package. `SessionLogTailer` byte-tails `~/.claude/projects/**/*.jsonl` and `~/.codex/sessions/**/rollout-*.jsonl` with persisted offsets; pure extractor structs derive per-call latency/throughput `ProbeSample`s (Claude: `api-request` ↔ `assistant.requestRef` join; Codex: `task_started`→`task_complete` + gap-filtered `token_count` bursts); the `PassiveProber` actor runs the 60 s scan loop, seeds a 7-day launch backfill, emits an unauthenticated robots.txt control probe while measuring, and feeds the same `SampleStore` the limits poller writes. Pure `BaselineEngine` (median/MAD z-scores per provider+model+segment) and `VerdictEngine` produce verdicts + divergence copy; AppModel renders chip/sparklines/banner. The only network code added in M3 is `statusPage()` GETs (task 10) and the control probe — everything else is local file reads.

**Tech Stack:** Swift 6.4 toolchain, swift-tools-version 6.2, Swift 6 mode, macOS 14+, SwiftUI `MenuBarExtra`, Foundation only (`Data`, `FileManager`, `JSONDecoder`, `URLSession` for control/status GETs). Swift Testing. **No Network.framework stub server needed — nothing streams live.**

**Spec:** `docs/superpowers/specs/2026-10-20-semafor-design.md` (revision 2 — passive-first, committed `e391a0f`)

## Global Constraints

- swift-tools-version 6.2, `swiftLanguageModes: [.v6]`, `.macOS(.v14)`; zero third-party dependencies; Foundation only.
- Passive reads only: the passive pipeline makes **no network calls and no provider-authenticated requests**. Only task 5 (control GET, unauthenticated) and task 10 (status GETs) touch the network.
- Credentials never logged/stored/in error strings; user-visible text passes `redact()`. The sample store holds only probe/control/status/limit records. **Session-log message *content* must never reach the store or logs** — samples carry only ids, model slugs, numbers, timestamps.
- Verdict rules are a pure function — all inputs explicit (spec §8.2). Priority: `UNKNOWN > LIMITED > CRAWLING > DEGRADED > BUSY > OK`.
- Every task ends with `swift test` green and its own commit. Beacon-style imperative commit messages. Swift Testing (`@Test`, `#expect`).

## Review Focus

Failure modes the spec implies; each gets its pinning test in the named task:

- **Torn/rotated log lines** — a half-written final line is held (offset not advanced), not counted corrupt; a session file replaced mid-tail (offset > file size after rotation) restarts that file at 0 without crashing (Task 3).
- **Incomplete sessions** — request lines that never get assistant replies, or rollouts without `task_complete`, produce **no samples** — an aborted/interrupted session must not poison baselines (Task 4, 5).
- **Restart duplicates** — killing Semafor mid-day and relaunching re-enters the tail at persisted offsets; missing state ⇒ full re-backfill, and read-path dedupe by `sessionKey` means zero duplicate samples (Tasks 1, 3, 7).
- **Idle-gap throughput artifact** — a 3-minute tool call between two `token_count` events must not read as 0.1 tok/s crawl (burst-adjacency + output-token floors) (Task 5).
- **VPN flake misdiagnosis** — control probe bad ⇒ `UNKNOWN(network)`, DEGRADED/CRAWLING and the banner suppressed — the spec §13 acceptance (Tasks 6, 9).
- **Baseline poisoning / flapping** — one 100 s outlier among fast samples must not fire DEGRADED (median/MAD + floor + N-consecutive per model); learned↔default switch exactly at 20 samples (Task 8).
- **Clock anomalies** — samples with future timestamps excluded everywhere; non-ISO/missing timestamp fields skipped, not fatal (Tasks 4, 5, 8).

      public init(quietPeriod: TimeInterval = 2)
      public mutating func ingest(_ line: TailedLine)      // parse; ignore non-JSON and irrelevant types
      public mutating func finish(now: Date) -> [ProbeSample]

  Parse rules (tolerant DTOs — any missing/odd field skips the line, never throws):
  - `type == "api-request"` with `querySource == "repl_main_thread"` **or `querySource` absent**: pending[requestRefKey] = {startTs: timestamp, file: url.path, seen assistant lines: none, lastTouch: timestamp}; `requestRefKey` = the line's `id`.
  - `type == "assistant"` with `requestRef` matching a pending request: first line ⇒ `firstTs`, last ⇒ `lastTs` (running max), `tokens = max(output_tokens over lines)`, `model = requestedModel ?? message.model`.
  - A newer `api-request` in the same file with greater `startTs` **supersedes** older unfinished pendings.
  - `finish(now:)`: a pending completes when it has ≥ 1 assistant line AND (`now − lastTouch ≥ quietPeriod` OR superseded). Sample: `sessionKey = "<fileName>#<requestRefKey>"`, `timestamp = startTs`, `ttft = firstTs − startTs`, `duration = lastTs − startTs`, `tokensPerSecond = tokens / duration` guarded `duration ≥ 0.5 && tokens ≥ 10` else nil, `outcome = .ok`, `model` = observed model (fallback `"claude-unknown"`). Superseded pendings with **zero** assistant lines ⇒ one `.timeout` sample each (ttft/duration nil, tokens nil) — stalled-request evidence — then are dropped. Completed pendings are dropped after emission (idempotence across calls comes from store-side dedupe).
  - Non-ISO8601 or future-dated (`startTs > now + 5 min` at finish) lines ⇒ sample skipped (clock anomaly guard).

### Task 7: PassiveProber actor

**Files:**
- Create: `Sources/SemaforCore/Probing/PassiveProber.swift`, `Tests/SemaforCoreTests/Probing/PassiveProberTests.swift`

**Interfaces:**
- Consumes: `Provider` (for `sessionLogPaths`), `SessionLogTailer`, `SessionLogExtracting` implementations, `ControlProbing`, `LimitsWriting`, `AppSettings` (Task 2).
- Produces:
  ```swift
  public actor PassiveProber {
      public init(providers: [any Provider], tailer: SessionLogTailer,
                  extractors: [ProviderID: any SessionLogExtracting],   // fresh instances
                  control: any ControlProbing, writer: (any LimitsWriting)?,
                  settings: AppSettings, dateNow: @escaping @Sendable () -> Date = Date.init,
                  clock: some Clock & Sendable = ContinuousClock())     // ManualClock in tests
      // (init declared generic `init<C: Clock & Sendable>(...) where C.Instant.Duration == Duration`
      //  exactly like PollScheduler's — this form is the one to copy)
      public func start()                       // backfill once, then the 60 s scan loop
      public func scanNow() async               // one pass (used by "Test now" and tests)
      public func latestProbes() -> [ProbeSample]          // newest per provider+model
      public func measuredCountToday(provider: ProviderID) async -> Int   // .ok samples, local day
      public nonisolated func updates() -> AsyncStream<[ProbeSample]>     // latestProbes snapshot
  }
  ```
  Semantics:
  - Backfill (once, first `start()`): for each provider, files under its `sessionLogPaths` whose path/name date falls within `backfillDays` (claude dirs are flat per project; codex path is `…/yyyy/MM-dd/` — tolerate layout drift: use file content date via tailer read window instead when path parse fails ⇒ include, dedupe covers re-reads) are tailed from offset 0 **into a throwaway extractor**, samples appended. Live extractors per provider then continue from current offsets. Backfill does **not** consult the store and there is **no in-memory seen set**: offset-resume prevents re-ingest, and state-loss re-backfill is fully covered by the store's read-path `sessionKey` dedupe (Task 1).
  - Scan pass: per provider `pendingLines(in: sessionLogPaths, namePattern: "*.jsonl")` → `ingest` into that provider's running extractor → `finish(now: dateNow())` → append `.probe` per sample + update latest map + publish.
