# Semafor M1+M2 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`[ ]`) syntax for tracking.

**Goal:** A macOS menu bar app that shows live rate-limit windows and burn-rate projections for the Claude (Claude Code) and Codex/Astra (ChatGPT) subscriptions, using the CLIs' own on-machine credentials.

**Architecture:** One SwiftPM package: `SemaforCore` library (providers, HTTP, polling actor, JSONL sample store, burn-rate math, view models) + thin `SemaforApp` SwiftUI executable (MenuBarExtra). Zero third-party dependencies. Providers sit behind one protocol so endpoints/credentials are the only surface that talks to providers' APIs.

**Tech Stack:** Swift 6.4 toolchain, swift-tools-version 6.2, Swift 6 language mode, macOS 14+, SwiftUI `MenuBarExtra`, Foundation `URLSession`, Security (Keychain), ServiceManagement, Swift Testing (`import Testing`). Packaging scripts adapted from `~/Git/timkoopmans/beacon/scripts/`.

**Spec:** `docs/superpowers/specs/2026-10-20-semafor-design.md`

**Scope:** Milestones M1+M2 only. M3 (latency probes, baselines, verdicts, divergence banner) and M4 (session-log watcher, notifications, settings polish) get separate plans **after** this plan's Task 6 spike records the real endpoint payloads — their DTOs must be planned against captured reality, not guesses. `Provider.probe`/`statusPage` and `ProbeSample`/`StatusPageState` types are defined here so M3 plugs in without protocol churn, but their behavior is stubbed (`ProviderError.unimplemented`).

## Global Constraints

- swift-tools-version 6.2, `swiftLanguageModes: [.v6]`, platforms `.macOS(.v14)` minimum.
- Zero third-party dependencies. Foundation / SwiftUI / Security / ServiceManagement only.
- No Dock icon: `LSUIElement` in the packaged plist **and** `NSApp.setActivationPolicy(.accessory)` at runtime (so `swift run` dev mode also behaves).
- Bundle id `com.timkoopmans.semafor`, app name `Semafor`, deployed to `~/Applications` (Beacon's pattern).
- Credential material (keychain item, `auth.json` contents, bearer/account headers) never appears in logs, the sample store, or error strings. All smoke output passes through the redaction helper.
- Every task ends with `swift test` green and its own commit. Commit style: Beacon's short imperative sentences ("Add poll scheduler", "Fix reset countdown when resetsAt is in the past").
- Tests use Swift Testing (`@Test`, `#expect`, `@Test(.timeLimit:)` where useful), not XCTest.

## Review Focus

Failure modes the spec implies that no single task's happy-path tests cover. Each line has a pinning test in the task named:

- **Missing/expired credentials** — keychain item absent, `auth.json` absent or missing `tokens.*` keys → section shows "run `claude` once" / "run `codex` once", icon goes grey, no crash, no alert loop (Tasks 4, 5, 10).
- **Endpoint drift** — JSON keys renamed/null/absent, percent scales wrong → tolerant decode to `nil` percent with a "not reported" row, never a crash (Tasks 4, 5 with malformed fixtures).
- **Time anomalies** — `resetsAt` in the past, sample timestamps in the future or non-monotonic, clock jumps → countdown renders "resetting…", bad samples filtered before slope, `Projection` goes `nil` rather than nonsense (Tasks 9, 10).
- **Store corruption / interleaved writes** — trailing half-line from a crash, blank lines → reader skips and reports count, no data loss, no throw (Task 8).
- **Flaky network** — timeout, DNS failure → previous snapshot kept and marked stale after 3× poll interval, exactly one attempt per interval (no retry storms) (Task 7).

### Task 9: Burn-rate estimator (pure math + copy)

**Files:**
- Create: `Sources/SemaforCore/BurnRate/BurnRateEstimator.swift`, `Tests/SemaforCoreTests/BurnRate/BurnRateEstimatorTests.swift`

**Interfaces:**
- Consumes: `UsageWindow`, `WindowName`.
- Produces:
  - `enum BurnRateEstimator` with:
  - `struct Projection: Equatable { slopePercentPerHour: Double; eta: Date?; band: Duration?; headline: String }`
  - `static func project(samples: [(at: Date, usedPercent: Double)], now: Date, minSpan: Duration = .hours(2), flatEpsilon: Double = 0.01) -> Projection?` — **rule:** drop samples with `at > now`; require ≥2 valid samples spanning ≥ `minSpan`, else `nil`; least-squares slope; if |slope| < flatEpsilon → Projection with `eta: nil`, `headline: "no measurable drain in the last 2h"`; else `eta = now + remaining/slope`; band = `max(30 min, |eta(firstHalfSlope) − eta(secondHalfSlope)|)`; `headline = "at this pace, gone ~Thu 14:00 (±2h)"` — weekday-abbrev + 24h local time, band rounded to whole hours, hours < 1 rendered in minutes.
  - `enum PaceStatus: Equatable { case ok, aheadOfPace(deltaPoints: Double), notEnoughData }`
  - `static func pace(usedPercent: Double?, windowSeconds: Int?, resetsAt: Date?, now: Date, threshold: Double = 15) -> PaceStatus` — elapsed% = fraction of window already gone (from `resetsAt − windowSeconds`); `used − elapsed > threshold` → `.aheadOfPace`; nil inputs → `.notEnoughData`.
